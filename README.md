# 🧴 Gestão de Vendas - Detergentes

Sistema para automação de pedidos, cadastro de clientes e controle de pagamentos, substituindo promissórias de papel.

## 🛠️ Tecnologias
- Java 17 + Spring Boot
- Spring Data JPA
- MySQL
- Maven
